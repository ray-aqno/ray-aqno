### Hey, I'm Rayyan, and I build tools that help people build.

My foundation is agentic systems: AI that gets real work done, not just answers. I'm drawn
to the parts most people skip, and I'd rather build something people trust than something
that only demos well. Right now I'm a Tech & Innovation Intern at NaviStone, where I'm
building a marketing ops brain.

<br clear="left"/>

That foundation comes from the projects I build on my own:

- 🏛️ **[Toto-Wolff](https://github.com/ray-aqno/Toto-Wolff)**: persistent governance for
  Claude Code. A council of scouts, analysts, and a chairman reviews each architectural
  decision and writes it to a durable record, so later sessions inherit the ruling instead
  of arguing it again.
- 🔧 **[qwengineering](https://github.com/ray-aqno/qwengineering)**: an agent system that
  runs entirely on one 16GB M1. A single Qwen2.5-7B-Instruct model fills every role. A
  LangGraph state machine routes each step, and a fresh system prompt turns the model into
  the planner or any worker. No cloud inference.
- 📈 **[crescent-quant-agent](https://github.com/ray-aqno/crescent-quant-agent)**: an ethical
  trading system where a compliance check blocks every trade until it passes. Agents talk
  over a Kafka event bus, pull their rules with RAG, and train against a simulator. A person
  approves the final trades from a review dashboard.
- 🧠 **[mental-health-database](https://github.com/ray-aqno/mental-health-database)**: a
  searchable map of mental health resources across Midwest colleges, aimed at incoming
  freshmen. I scraped the listings with Scrapy, built the app in ASP.NET Core, and shipped
  it to my graduating class of about 900 seniors.
  **[Live app →](https://mental-health-database.onrender.com)**
